# EMBER ISLE — 灯りの島

低解像度のローポリ3D探索ゲーム。光る欠片を5つ集め、中央の灯台に戻るとクリア。

## 操作

- PCはWASDまたは矢印キーで移動、Q/Eでカメラ回転。
- スマホは画面左下の移動ボタンと右下の回転ボタンを長押し。
- 欠片は距離1未満まで近づくと自動回収。
- 最初からボタンで初期化。進行の保存は行わない。

## 構造

外部ライブラリや画像に依存しないindex.htmlの1ファイル。Canvas 2D上で3D頂点を透視投影し、低解像度の画面を拡大してピクセル調に表示する。木・灯台・旅人は立方体と四角錐の組み合わせ。

| 関数・データ | 役割・変更箇所 |
|---|---|
| shardLocations / trees / rocks | 欠片・木・岩の配置。座標はx,z、yが高さ |
| reset / start | 初期化とプレイ開始 |
| canWalk | 島の端・灯台・木の幹への衝突判定。岩と枝葉は通り抜ける |
| update | 入力による移動、回収、クリア条件。斜め移動を正規化 |
| project / face | カメラ空間への変換、透視投影、距離による霧 |
| box / pyramid | 立方体と四角錐の面生成 |
| render | 水面、地面、オブジェクトの順に描画。各層は奥からソート |
| frame | 描画ループ。dtを最大0.05秒に制限して復帰時の瞬間移動を防ぐ |
| イベント登録 | キー入力、タッチのポインターキャプチャ、非表示時の入力解除 |

## 状態

playerは現在位置、yawは視点の水平角、shardsは各欠片の取得状態。activeが開始状態、completedがクリア状態、elapsedが表示中のプレイ時間。背景タブでは進行せず、入力も解除する。

## 描画の制約

高さ270ピクセルの内部描画を使用する。幅は画面比率に合わせ200〜640ピクセル。簡単な面の奥行きソートで描画するため、複雑な形状を増やすと面の前後関係に誤差が出る場合がある。ニアクリップにかかった面は省略する。モバイル実機での性能確認は未実施。
