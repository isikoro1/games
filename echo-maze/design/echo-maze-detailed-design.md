## 1. ファイル構成と初期化

`echo-maze/index.html` に画面要素、CSS、ゲームロジックを格納する。盤面はCanvas 2D、ステージ情報・操作ボタン・メッセージはHTML要素で表示する。スクリプトは必要なDOM要素を取得し、クリックとキーボードのイベントを登録したあと、`prepare()`、`draw()` の順に呼ぶ。

## 2. 状態とデータ構造

| 変数 | 内容と初期化 |
|---|---|
| `phase` | `ready`（開始待ち）、`memorize`（記憶中）、`play`（探索中）、`won`（クリア）。初期値は `ready` |
| `level`, `size` | ステージ番号は1から開始。盤面の一辺は `Math.min(4 + level, 10)` |
| `walls` | 長さ `size * size` の配列。各要素の下位4ビットが4方向の壁を表す。ビットが1なら壁あり |
| `player`, `exit` | 現在地と出口のマス番号。ステージ開始時はそれぞれ0と `size * size - 1` |
| `steps`, `echoes` | 歩数とエコー残数。各ステージで0と2に初期化 |
| `revealUntil`, `bumpUntil` | 壁の一時表示と衝突表示の期限。 `performance.now()` と同じ基準のミリ秒で保持。各ステージで0に初期化 |
| `bumpDirection`, `frame` | 最後にぶつかった壁の方向と、予約したアニメーションフレームのID |

マス番号は行優先で `i = x + y * size`。座標は `x = i % size`、`y = Math.floor(i / size)`。原点は左上で、右と下が正。

| 方向番号 `dir` | 方向 | `[dx, dy]` | 壁のビット値 |
|---|---|---|---:|
| 0 | 上 | `[0,-1]` | 1 |
| 1 | 右 | `[1,0]` | 2 |
| 2 | 下 | `[0,1]` | 4 |
| 3 | 左 | `[-1,0]` | 8 |

## 3. 迷路生成

`generateMaze(width)` はランダム化した深さ優先探索で迷路を作る。

1. 全マスを壁あり（15）で初期化。マス0を訪問済み集合と探索スタックに入れる。
2. スタックの末尾のマスから、盤面内かつ未訪問の隣接マスを候補にする。候補がなければスタックから取り除いて戻る。
3. 候補を `Math.random()` で1つ選び、現在マスの進行方向と隣接マスの反対方向の壁をビット演算で消す。反対方向は `(dir + 2) % 4`。
4. 隣接マスを訪問済みにしてスタックに積む。スタックが空になるまで繰り返し、壁配列を返す。

壁を開くのは未訪問マスへ進む場合だけなので、全マスがつながり、ループがない。スタートから出口への経路は1つ。盤外へ通じる壁は開かない。時間・補助メモリともに盤面のマス数に比例する。

## 4. 操作・状態更新

| 処理 | 呼び出し元 | 処理内容 |
|---|---|---|
| `prepare()` | 初期化、クリア後の `start()` | サイズを計算して迷路を生成。現在地、出口、歩数、エコー残数、表示期限を初期化して表示を更新 |
| `start()` | 主ボタン | `won` の場合はステージ番号を増やして `prepare()` を実行。 `memorize` に遷移し、壁の表示期限を現在時刻＋5000msに設定。主ボタンを無効化して描画 |
| `echo()` | エコーボタン、条件を満たすSpace | 探索中で残数があり、表示期限を過ぎている場合のみ実行。残数を減らし、期限を現在時刻＋1300msに設定して再描画 |
| `move(dir)` | 方向ボタン、移動キー | 探索中のみ実行。現在マスに対象方向の壁がある場合、衝突方向と期限（現在時刻＋350ms）を更新。通れる場合は `player += dx + dy * size` で移動し、歩数を加算。出口到達時は `won` に遷移して主ボタンを有効化。最後に描画 |
| `updateStats()` | 初期化、状態・記録更新 | ステージ番号を最低2桁で表示し、歩数と残数を反映。探索中・残数あり・壁の一時表示期限を経過の3条件がそろったときだけエコーボタンを有効化 |

`keydown` ではAlt・Ctrl・Meta付きの入力を除外し、キー名を小文字化して方向に変換する。移動キーの既定動作は抑止する。探索中にボタン以外へフォーカスがあるときはSpaceの既定動作を抑止し、リピート入力を除いてエコーを呼ぶ。ボタンにフォーカスがあるときのSpaceはブラウザ標準のクリックに任せる。

## 5. 描画と時間制御

1. `draw(now)` の先頭で前回予約したフレームをキャンセル。引数が省略された場合は `performance.now()` を使う。
2. 記憶中に期限へ到達したら探索中へ遷移。期限前は残り秒数を `Math.ceil((revealUntil - now) / 1000)` で表示する。探索中に一時表示期限を過ぎた場合は期限を0に戻し、エコーボタンの有効状態を更新する。
3. 540×540のCanvasに描画。座標(20,20)から幅500の領域を `size` 等分し、各マスを市松模様で塗る。壁は該当ビットが立ち、全壁表示中・外周・衝突表示対象のいずれかであるときに描く。衝突した側の線を赤く太く描く。
4. 出口は金色のひし形、現在地はミント色の円として各マスの中心に描く。
5. 記憶中、エコー表示期限前、衝突表示期限前のいずれかなら `requestAnimationFrame(draw)` で次のフレームを予約。通常探索中は入力時に再描画する。

## 6. 受け入れ確認項目

| 確認項目 | 期待結果 |
|---|---|
| 初期表示と開始 | 5×5で開始。開始後5秒間は移動不可。期限後に探索を開始し、内側の壁が消える |
| 壁への移動 | 現在地と歩数を維持。該当方向の壁が短時間赤く表示される |
| 通路への移動 | 指定方向に1マス進み、歩数が1増える |
| エコー | 1回で残数が1減る。約1.3秒で内側の壁が消える。表示中と残数0では再発動しない |
| クリアと進行 | 右下へ着くと歩数を表示。次のステージで歩数0・残数2。盤面は10×10で拡大を止める |
| ブラウザ操作 | キーと画面の方向ボタンで移動できる。狭い画面で盤面と操作欄が縦に並ぶ |
